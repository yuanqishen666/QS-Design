# 微信小程序平台适配

## 能力分层

1. **通用可靠层**：基础组件、页面导航、表单、列表、媒体和普通 CSS 动画。
2. **Skyline 增强层**：Worklet 动画、手势协同、共享元素、半屏与高性能滚动。
3. **视觉运行时层**：Canvas、Lottie 或自绘内容；必须保留语义操作和失败占位。

## 设计约束

- 胶囊按钮、安全区域、页面栈和返回是结构条件，不是最后补边距。
- 授权只在动作需要时触发，拒绝后仍有可理解路径。
- 分享、支付、订阅消息和隐私必须按官方能力设计真实结果与失败状态。
- 高频触摸更新在渲染层完成，避免每帧 `setData`；滚动和自定义手势明确竞争关系。
- Skyline 能力需记录最低基础库并为 WebView/旧版客户端准备等价降级。

## 验证

- 微信开发者工具只用于初筛；至少验证 iOS/Android 真机。
- 检查首屏、分包、弱网、图片解码、长列表、后台恢复、字体与系统深色模式。
- 以微信官方文档和 `wechat-miniprogram` 官方示例仓库为能力依据，不从 H5 效果反推支持。
