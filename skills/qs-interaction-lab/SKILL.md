# QS Interaction Lab

把现实动作拆成可迁移的因果结构，而不是建立物品动画模板。结果必须增强理解、操控、反馈或记忆，并能被用户打断、取消或降级。

## 工作方式

1. 读 [具身交互机会扫描](../../core/references/embodied-opportunity-scan.md) 和 [交互基因](../../core/references/interaction-genome.md)。
2. 从核心业务动作提取转移、容量、阻力、阈值、分离、残留、旋转、惯性、组装、形变、擦除或轨迹等因果关系。
3. 给候选机制评分。未达到采用阈值时使用普通直接操控；不要为了新奇强行动画。
4. 先制作 3–8 秒可操作探针，至少覆盖连续映射、阈值、提交、取消、打断、稳定、减弱动态和替代输入。
5. 探针通过后才进入整页；根据目标平台选择 DOM/CSS、Motion/GSAP、Rive、Canvas/WebGL、SwiftUI 或 Compose，不假设跨平台等价。

使用 [探针契约](references/probe-contract.md) 记录状态。可复用行为代码在 `core/runtime/`；它提供状态与物理辅助，不提供视觉模板。

## 禁止

- 不把用户举过的杯子、票根、唱片或任何单一物品写成全局默认动画。
- 不用自动播放代替用户操控，不用触感/声音掩盖状态不清。
- 不让高频动作变慢，不让隐喻成为唯一可发现入口。
- 不在无法验证的目标平台上承诺浏览器演示效果。
