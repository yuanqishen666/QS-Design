# 自适应方向策略

方向数量由真实设计不确定性决定，不再固定为三。

| 条件 | 输出 |
|---|---:|
| 机械修改、明确小改、设计系统内扩展 | 1 |
| 一个会改变结果的关键分歧 | 2 |
| 产品解释、任务结构或操控模型有多个真实分叉 | 3 |
| 已选方向深化 | 1 |
| 用户明确要求更多探索 | 用户指定，并明确精修与跨端成本 |

系统默认选择 1–3 个方向。用户可以明确指定更多；超过 3 个时必须展示成本说明，并优先交付方向样张而不是并行制作多套低工艺成品。方向数要说明理由，但不使用伪精确评分。

## 多方向交付

先制作可比较的方向样张：同一代表任务、相同业务结果、一个业务特有模块、关键操作、艺术指导、平台实现路径、收益成本和不可替换性。用户选择后再扩展为完整原型。不要为了数量同时制作多套低工艺全量成品。

## 真实差异

多方向必须分别回答产品解释、信息拓扑、操控模型、业务主角、艺术指导和用户结果。Light/Dark、设备尺寸、删减功能、换色、圆角、字体或插图不算独立方向。

方向可以共享业务模型、数据、动作合同和无视觉基础逻辑，不能复制完成稿骨架再换皮。平台版本是同一方向的原生表达，不是额外方向。

## 比较与选择

同时展示真实渲染、体验入口、具体差异、收益、成本和未知项。不替用户预选。用户可以选择、要求调整、软重置或硬重置。
