# 模糊语义解释

“专业但不冷”“高级但不疏离”“有趣但耐用”等表达不能直接映射成风格标签。

## 解释链

```text
用户原话 → 语义张力 → 当前业务含义 → 可观察体验 → 内容/结构/视觉/交互决定
```

每份语义意图保留用户原话、张力、业务解释、可观察标准、视觉影响、交互影响、拒绝的捷径和未确定项。

## 风格捷径

高级不自动等于黑金，科技不自动等于蓝紫渐变，友好不自动等于大圆角插画，专业不自动等于企业蓝，极简不自动等于空。形式可以使用，但要有当前业务和艺术指导依据。

## 提问

只有答案会改变主任务、产品解释、操控模型或视觉基调时才提问。使用高信息量对比，例如“有趣应发生在操作过程还是完成结果”，不要问“喜欢什么风格”。
