# 视觉元素语法与表面纪律

视觉独特性不是把卡片换成另一套卡片，也不是从风格名称里抽签。先定义页面靠什么被看见、被理解和被记住，再决定组件。

## 先选视觉载体

每个正式方向必须选择一个 `dominant_visual_carrier`，并最多选择少量 `supporting_visual_carriers`。载体描述信息或体验如何进入画面，不是风格标签。

| 载体 | 可以承载什么 | 常见表达 |
|---|---|---|
| `domain-object` | 业务对象本身 | 商品、路线、文物、票据、语言片段、空间或设备成为主角 |
| `typography` | 内容语气、层级和节奏 | 字号跃迁、字重、字宽、混合字族、边注、首字、数字排印 |
| `imagery` | 证据、情境、人物和氛围 | 摄影、裁切、拼贴、全出血图像、序列帧、图文穿插 |
| `data-diagram` | 关系、变化、比较和因果 | 图表、路径、时间轴、拓扑、热区、标注和数据图形 |
| `shape-field` | 分区、方向、能量和构图张力 | 大尺度几何、剪影、遮罩、缺口、有机形、色域 |
| `material-texture` | 触感、年代、环境和品牌气质 | 纸、墨、织物、木、金属、玻璃、黏土、颗粒；必须与业务语境相关 |
| `color-light` | 状态、焦点、温度和空间深度 | 双色、专色、环境光、聚光、明暗场；不能退化成无意义渐变 |
| `illustration-symbol` | 概念、叙事和独有识别 | 定制图标、象形系统、插画角色、领域符号；不使用随机线性图标填空 |
| `spatial-composition` | 阅读顺序和身体感 | 不对称、重叠、裁切、尺度跳变、越界、前后景、编辑式分栏 |
| `motion-behavior` | 状态转换、因果和连续操控 | 形态转换、滚动叙事、拖拽物理、焦点跟随、路径展开；必须服务任务 |

“极简”不等于没有载体。极简方向可以让排印、比例、留白和内容密度成为主导载体，但不能用一组等权卡片代替视觉论点。

## Art Direction 的元素合同

正式方向除原有字段外，明确：

- `dominant_visual_carrier`：唯一主导载体；
- `supporting_visual_carriers`：辅助载体，通常不超过两个；
- `surface_strategy`：哪些信息需要实体表面，哪些直接进入画布；
- `composition_logic`：载体如何决定视线、比例、重叠、裁切和节奏；
- `image_strategy`：图像、数据或领域对象与文字的关系；
- `material_logic`：材料和光感为何属于这个业务；
- `motion_language`：状态如何转换，而不是列一组 hover 动效；
- `restraint_budget`：哪些效果只能出现一次，哪些明确禁用；
- `fallback_strategy`：低性能、减少动态、无图片或窄屏时如何保持主张。

方向描述应包含“概念隐喻 → 主导载体 → 构图拓扑 → 表面策略 → 字体行为 → 图像/数据关系 → 材料/光线 → 标志性交互 → 降级”的完整链路。只写颜色、圆角、阴影和组件名称不构成艺术指导。

## 表面不是默认容器

卡片、面板、Tile 和带边框容器只在至少满足一项时使用：

1. 内容需要作为独立对象被选择、拖动、展开或链接；
2. 内容拥有独立状态、权限、生命周期或恢复动作；
3. 异质信息需要被理解为一个不可拆分的语义组；
4. 项目需要脱离当前上下文仍能成立，例如可分享摘要；
5. 平台约定要求明确的交互或模态边界。

以下情况优先使用其他关系：

- 同构数据：列表、表格、时间轴、图像网格或直接标注；
- 层级关系：字号、字重、缩进、对齐、留白和位置；
- 连续过程：路径、阶段带、滚动叙事或状态变形；
- 场景与证据：全出血媒体、局部裁切、拼贴和图文穿插；
- 空间分区：背景场、色域、形状、光线或平台原生分组。

禁止用“加边框、加圆角、加阴影、放进白底”作为默认完成手段。避免卡片套卡片。连续同构内容若出现三个以上同样表面，必须执行移除容器测试：去掉外框后若仍能靠排印、对齐和间距表达关系，就移除表面。

## 同内容样张

需要探索多个视觉方向时，固定代表任务、真实数据、信息量、主要动作和业务结果，只改变设计语法。方向之间至少在以下维度中的两个形成实质差异：

- 主导视觉载体；
- 构图逻辑；
- 表面策略；
- 图像或数据关系；
- 材料与空间语言。

推荐形成“排印/编辑”“数据/空间”“材料/图像”等不同机制的样张，而不是同一 DOM 骨架换色。样张比较的是阅读、判断和操作体验，不是风格名称的吸引力。

## 外部参考蒸馏

外部网站、图库、录屏和社区案例只用于一次性研究，不得成为 skill 运行时依赖。研究时按以下格式提取机制：

1. 观察：页面真实使用了什么布局、排印、媒体、形状、材料、动效和状态；
2. 作用：它改变了识别、层级、理解、情绪还是操控；
3. 约束：什么内容规模、设备、性能和无障碍条件下成立；
4. 转译：把机制改写成不含站点名称、作品名称和独特表达的本地规则；
5. 组合：至少与业务事实和另一个独立机制重新推导，不复制整套骨架；
6. 验证：外部来源不可访问时，本地合同、规则和测试仍能独立运行。

不要把截图、链接、提示词原文或站点风格名称当作长期能力。需要保留来源与许可时，放在任务研究记录，不进入分发所必需的执行路径。

## 验证

- **移除容器**：去掉边框、底色和阴影后，信息关系是否仍清楚；若清楚，表面可能多余。
- **轮廓与缩小**：在模糊或 25% 缩放下，画面是否仍有明确主次，而不是均匀矩形阵列。
- **灰度层级**：不用颜色时，比例、位置和排印能否维持阅读顺序。
- **元素生态**：当任务明确要求独特视觉或品牌表达时，首个代表视口是否存在一个非界面镀铬的主导载体；若选择排印/极简，是否真的有尺度与节奏，而非卡片汤。
- **业务追踪**：移除主导载体后，业务理解、判断或感受损失了什么。
- **高频疲劳**：光效、材质、非对称和动效在重复使用后是否仍可承受。
- **降级可用**：减少动态、无图片、窄屏、高对比和字体放大时仍能完成主任务。

视觉效果不因“装饰”二字自动无效；情绪、品牌和愉悦也可以是正当目标。但每个强元素都要说明它承担的作用、出现频率和降级方式。
