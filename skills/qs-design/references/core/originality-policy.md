# 原创性规则

## 形成原创方案

1. 先从任务、内容、平台和真实资产形成设计问题，不从风格标签开始。
2. 从多个独立来源抽取机制：例如一个来源研究内容层级，另一个研究动态连续性；重新组合并解释为何适合当前任务。
3. 记录采用、改变和拒绝了什么。没有新增决策知识的样张不进入正式库。
4. 品牌资产优先来自官方媒体包、官网或应用商店；保留许可与署名。
5. 第三方截图保持临时、本地、链接式使用，正式库只保留自有代码、预览和抽象观察。

## 相似度风险

如果单一来源同时决定了下列三项以上，重新设计：

- 整页骨架或独特构图。
- 色板与渐变关系。
- 字体组合与字号节奏。
- 独特图像/插画处理。
- 标志性交互与运动编排。

自动相似度只能提示风险，不是法律结论。最终检查来源许可、可识别表达、组合方式和独立设计理由。

## 样张来源文件

每个正式样张使用 `provenance.json` 记录：

```json
{
  "original": true,
  "sources": [{"url": "https://...", "observed": "mechanism only"}],
  "assets": [{"path": "...", "license": "...", "source_url": "..."}],
  "novel_decisions": ["本样张独立新增的设计决策"],
  "redistribution": "allowed"
}
```

不复制其他 skill 的样张、提示词段落、分类名或脚本实现。可以研究其公开原理，但要使用本项目自己的命名、数据结构、代码和测试。
