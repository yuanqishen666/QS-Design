# 交互基因

交互案例必须能回答“用户为什么动、状态怎样变、被打断后怎样恢复”，不能只记录缓动和时长。

## 三类动效

| 类型 | 价值 | 默认策略 |
|---|---|---|
| 生产性动效 | 响应、状态、连续性、空间关系和操作反馈 | 使用平台熟悉行为，快速、安静、不阻塞 |
| 表达性动效 | 感知品质、品牌性格、趣味、里程碑和情绪奖励 | 集中在关键、低频时刻，保持统一运动语言 |
| 环境装饰动效 | 氛围、背景和纯视觉表现 | 谨慎使用，不持续竞争注意力，允许移除或降级 |

没有业务含义不等于没有体验价值。“事事有回应”属于反馈价值。删除动画后若理解、操控或确认受损，应保留；若不受损，继续判断它是否明显提升响应感、连续性、感知品质、品牌性格或适度愉悦。只有没有这些收益，或收益低于等待、注意力、重复、性能和无障碍成本时，才删除。

## 记录维度

| 维度 | 问题 |
|---|---|
| 目的 | 解释、连续性、反馈、操控、等待、确认、恢复或愉悦？ |
| 输入 | 点击、按压、拖动、甩动、捏合、旋转、滚动、键盘、语音、传感器？ |
| 连续映射 | 位置、速度、角度、压力、时间如何映射到视觉与状态？ |
| 约束与物理 | 范围、弹簧、衰减、摩擦、碰撞、重力、阻力、形变？ |
| 阈值 | 预览、可提交、危险、不可逆、完成在哪发生？ |
| 状态 | 静止、预备、操控、提交、取消、打断、回弹、稳定、残留？ |
| 反馈 | 视觉、文字、声音、触感和系统状态怎样分工？ |
| 可逆性 | 怎样取消、撤销、反向、重复进入？ |
| 降级 | 减弱动态、键盘、读屏、低性能和平台不支持时怎样完成？ |

## 动效预算

- 同一时刻尽量只有一个明显的视觉运动中心。
- 基础反馈可以分布在多处，但同类动作使用一致的速度、弹性、位移和反馈强度。
- 自动播放、循环、大面积位移和多元素错峰使用更高门槛；环境动效不能盖过任务内容。
- 退出通常比进入更快；动作开始后不要求用户等待动画结束。
- 动画完成只负责表现，不能决定业务是否成功。

## 频率门

- 高频核心动作：即时、安静、短或不动画；反馈优先于表演。
- 中频导航/编辑：用连续性和状态变化减少迷失。
- 低频完成/里程碑：可以更有性格，但不延迟下一任务。
- 首次教学：只在确有学习成本时使用，必须可跳过且不重复打扰。

## 实现不变量

- 新输入能接管当前运动；取消不会误提交。
- 状态结果不只靠运动表达，静止帧与辅助技术仍能理解。
- 速度在手势、释放与后续运动之间尽量连续。
- 触感/声音绑定因果节点，不为普通点击遍地播放。
- 复杂材质层不替代 DOM/原生语义层。
