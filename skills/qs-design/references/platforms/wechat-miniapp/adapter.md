# 微信小程序适配器 v3

先读取 Task Capsule、共享业务模型、连续性契约、语义意图和所选方向，再读 [微信平台约束](wechat-platform.md)。

## 原生表达

- 明确 WebView、Skyline、Worklet 和基础库版本；
- 处理胶囊、安全区、导航栈、授权、分享、支付和返回结果；
- 高频连续反馈不能依赖逐帧 `setData`；
- 复杂交互必须提供普通点击、键盘或低性能降级路径；
- 与其他平台共享业务状态和结果，不复制其控件和页面结构。

## 内容显隐

- 不依赖 hover 或长按发现信息；关键规则、金额、权限、后果和恢复常驻在决策点；
- 少数用户需要的短说明使用明确点击触发的披露层，较长或可交互内容使用普通组件页面或弹层；
- 表单保留可见标签与错误恢复，信息图标不能成为每个模块的固定装饰。

## 运行证据

优先使用开发者工具与 iOS/Android 真机。缺少工具或基础库证据时将相关能力标记 `unknown`。

由于开发者工具 CLI 与基础库存在版本差异，只运行任务明确提供的命令、参数和工作目录，不猜测全局安装路径。导航栈、文字缩放、关键内容可见性、披露触控等价性与低端降级分别需要断言证据。
