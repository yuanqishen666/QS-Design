# Web 平台适配

## 响应式关系

- 从内容最小可用宽度、并排关系和操作频率推导重排点，不以设备品牌命名断点。
- 宽屏增加并行上下文或持久工具，窄屏改为顺序任务；避免空洞拉宽。
- 长文、中英混排、200% 文本缩放、系统字体缺失和极长标签都要测试。

## 输入与导航

- 链接负责导航，按钮负责动作；表单使用真实标签、错误关联与提交语义。
- 焦点顺序与视觉顺序一致；弹层管理焦点、Escape 与恢复来源。
- 拖拽有按钮/键盘替代，触屏不依赖 hover，小目标扩大可点区域但不重叠。
- URL、刷新、深链、前进/返回与未保存状态保持一致。

## 动态与性能

- 直接操控从输入连续映射，不把每帧状态塞进高成本框架重渲染。
- 共享转场可用 View Transitions 或实际元素布局动画；需验证交互阻塞与中断。
- 对 Canvas/WebGL/Rive 提供语义镜像、静态替代和清晰的加载/失败状态。
- 测试布局偏移、长任务、低端移动设备、慢网、后台恢复和 `prefers-reduced-motion`。
