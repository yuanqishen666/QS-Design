# Web 适配器 v3

先读取 Task Capsule、业务模型、连续性契约、语义意图和所选方向，再读 [Web 平台约束](web-platform.md)。不要把 Web 页面当成其他平台的母版。

## 原生表达

- 使用语义 DOM、浏览器历史、键盘、焦点和可访问名称；
- 响应式由内容关系和窗口能力驱动，不以固定设备海报缩放；
- Canvas 只承担绘制，业务语义和替代操作保留在 DOM；
- 动效可打断并处理 `prefers-reduced-motion`；
- 真实检查窄、中、宽视口、长内容、键盘和滚动。

## 内容显隐

- 先用语义分组、标题层级、表格关系、表单结构和明确动作解释任务；不为每个 section 固定生成导语；
- 表单保留可见 label；placeholder 和 `aria-label` 不替代多数用户需要的标签或规则；
- 关键事实保持可见。Tooltip 只承载短、可选、非交互内容，并以 `aria-describedby` 关联可聚焦触发器；
- 运行时分别验证 hover、focus、Escape、悬停保持、持续显示和触控替代。原生 `title` 属性不能作为唯一实现，disabled 元素不能作为唯一触发器。

## 运行证据

可运行 URL 时使用浏览器运行器读取 DOM、可访问树、计算样式、布局和任务轨迹。只有源码时报告静态结论；无浏览器证据时将运行时项目标记为 `unknown`。

运行器接受显式 `target.url`、视口、动作、断言和截图路径，并优先使用目标项目已经安装的 Playwright。进程成功只证明页面已运行；键盘、可访问名称、关键内容可见性、披露输入等价性、reduced motion 与响应式断言没有证据时仍分别为 `unknown`。
