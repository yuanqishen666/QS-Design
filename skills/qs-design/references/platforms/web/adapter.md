# Web 平台适配器

把 Web 当作可变化窗口、键鼠与触屏共存、可导航且有语义的产品环境。视觉表达不能以牺牲 DOM、文本、焦点或性能为代价。

## 制作

1. 明确页面类型、核心任务、最小/最大有效宽度、输入方式、浏览器范围与现有技术栈；读取共享的 [内容设计](../../core/content-design.md)。
2. 用内容关系决定响应式重排；不要只设置几个断点按比例缩放。
3. 普通内容保留语义 DOM、真实按钮/链接/表单和可选择文本。Canvas/WebGL/Rive 只承载确有必要的视觉层。
4. 悬停只做增强，所有关键动作有键盘和触屏路径；路由、历史和浏览器返回保持可信。
5. 动态默认可打断，优先 transform/opacity；处理 `prefers-reduced-motion`、低性能档和后台恢复。

详细检查见 [Web 平台](web-platform.md)。高级连续交互按 [具身交互机会扫描](../../core/embodied-opportunity-scan.md) 通过后进入 [交互实验模式](../../modes/interaction-lab.md)。

设计阶段交付隔离且实际可打开的 Web 原型，不修改现有产品工程；必须走通核心路径并检查至少三个有意义的窗口宽度。用户批准后验证批准版本，再把设计迁移到现有工程并执行项目测试。
