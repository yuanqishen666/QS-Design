# 支付宝小程序适配器 v3.4

先读取 Task Capsule、Product Truth、Attention、Terminology、Prototype、共享业务模型、连续性契约、语义意图和所选方向，再读 [支付宝平台约束](alipay-platform.md)。

## 原生表达

- 明确客户端、基础库、渲染容器和支付/授权状态；
- 只在能力已验证时使用 `my.createAnimation`、movable-view、share-element、Lottie 或 Canvas；
- 保持金额、对象、提交、取消和返回语义；
- 复杂表现必须有普通组件降级；
- 平台版本是共享方向的原生表达，不是额外方向。
- 局部迭代使用稳定 `data-qs-id` 或项目已有测试 dataset 标识；identifier 不承担用户可见文案和无障碍名称。

## 内容显隐

- 不依赖 hover 或长按发现信息；支付、授权、金额、后果与恢复在决策点保持可见；
- 少数用户需要的短说明使用明确点击触发的披露层，较长或可交互内容使用普通组件页面或弹层；
- 表单保留可见标签，信息图标只有在存在明确解释对象和触控、辅助技术入口时才出现。

## 运行证据

使用开发者工具或实机证据。无法验证的动效、无障碍、关键内容可见性、披露输入等价性或组件能力报告 `unknown`。

只运行任务明确提供的开发者工具命令、参数和工作目录；命令成功不能替代无障碍、客户端兼容和支付/授权结果断言。
