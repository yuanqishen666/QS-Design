# 原创性与来源：借原则，也可以合法复用实现

参考用于扩展材料、任务理解与实现能力。原创设计来自对本次内容和操作的重新组织；不是要求所有基础代码都从零编写。

## 分清三种取用

| 取用对象 | 合理做法 |
|---|---|
| 设计原则与行为机制 | 理解为什么适用于原任务，再决定在当前产品怎样使用或改变 |
| 行为代码与基础组件 | 在许可、平台和项目依赖适合时直接复用或改造，保留必要版权与署名 |
| 品牌、图像、字体、声音等资产 | 按该资产自己的使用条件取得、使用与分发 |

导航、状态、草稿、输入处理和可中断运动等合法实现可复用。已有工程沿用自身能力；简单原型可使用本 skill 的行为辅助。无须为了“原创”重复编写易错的底层逻辑，也不默认引入完整视觉组件库作为页面骨架。

## 从参考形成自己的表达

先看原任务和内容，理解结构与操作解决了什么问题，再落到本产品：什么对象成为主角，用户操作什么，哪些内容联动，支持模块怎样分工。可以部分借鉴、重组或完全不用。

把现成整页换色、换文案再称为独立主题，缺少自己的产品解释。多方向分别构思，成熟行为可以一致，整页结构与材料由各自概念决定。范例中的字号、几何、颜色和节奏不自动推广为规则。

没有来源最低数量或固定证据组合。平台事实找技术依据，用户摩擦看具体反馈，视觉材料看作品和资产；选择取决于问题。其他清单和教程可以帮助发现线索，需要据此下结论时回到相应原始材料，不把二手概括当成亲自观察。

## 只处理实际采用项的使用边界

公开可见不等于可以复制或随 skill 分发。产品截图、设计资源、图标、字体、代码与社区作品分别按其条件使用；无法确认可分发的资产可以只保留参考链接或换用可用材料。

“可用于成品”和“可随模板或素材包再次分发”可能不同。Lottie、Rive 等运行时条款不自动覆盖社区作品；SF Symbols 与 Apple 设计资源也有各自的使用范围。真正引入时保留所需许可与署名，不对未使用条目新增审计。

从 [来源入口](source-registry.md) 与 [案例索引](examples/index.md) 按问题读取。索引中的访问提示帮助选择，不代表已取得资产或已操作产品；具体研究方法见 [参考研究](reference-research.md)。

## 不把别的工作流带进来

可借鉴有用知识与合法实现，不导入无关的评审分数、方向计数、固定设备画布、审批或整套展示模板。用户的当前目标决定范围，参考库提供选择空间。
