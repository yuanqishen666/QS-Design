# Changelog

## 3.2.0

- Added structure-first content admission and an information-visibility ladder that is conditioned by business criticality, audience and timing rather than a low-copy house style.
- Added a content visibility contract and public validation API for irreducible meaning, structural substitution attempts and disclosure selection.
- Restricted tooltips to short optional non-interactive content and kept critical rules, risks, consequences and recovery visible at the decision point.
- Added static checks for tooltip relationships, disabled or unfocusable triggers, interactive tooltip content, native-title reliance, visible form labels and repeated helper-copy templates.
- Added content-quality verification, cross-platform disclosure assertions and evaluation dimensions for explanatory dependency, critical-information visibility, input parity and false-deletion risk.

## 3.1.0

- Made Task Capsule read policy an enforced upper bound and split profile storage consent from per-task read authorization.
- Made soft reset exclude prior requirements, official constraints, semantic intent and continuity unless each is explicitly reauthorized.
- Restricted aspect inheritance to one parent and explicit merge to per-parent aspect maps; worker payloads now contain only authorized artifact contents and fail closed when content is missing.
- Added complete craft, generality and interaction-probe evidence contracts with source validation.
- Bound approval verification to task and candidate identity and removed ambiguous path/string artifact hashing.
- Added runner-attested platform assertion reports and prevented declared command assertions from claiming clean results.
- Added governance records to integrity-hashed portable sessions and made artifact reads allowlist-only.
- Strengthened candidate graphs, feedback scope, exception governance, public types, structured linting and evaluation comparability.
- Documented the boundary between model/input isolation and host-provided operating-system filesystem sandboxing.

## 3.0.0

- Replaced project-rooted memory with Task Capsule and pluggable stores.
- Added candidate lineage, rejected-candidate isolation, soft reset and hard reset.
- Added hashed context manifests and physical context-isolation requirement.
- Replaced fixed three-direction policy with adaptive one-to-three directions.
- Replaced `function-contract-only` with source classification and continuity contracts.
- Added business semantic model, fuzzy semantic intent and Art Direction Contract.
- Added business-specificity checks and QS house-style fingerprint comparison.
- Added semantic approval hashes and material-change detection.
- Added unified verification reports without a total style score.
- Added five platform adapters with explicit runtime unknown states.
- Added portable and projectless stores, v2 migration and v3 CLI.
- Added an allowlisted isolated worker runner and a one-way post-generation similarity gate.
- Added artifact-complete portable import/export and rejected-artifact content deletion.
- Added scoped decisions, expiring exceptions, per-component approval drift and ten-dimensional verification rules.
- Added explicit no-shell platform targets with required runtime assertion contracts.
- Upgraded content provenance, state/recovery coverage, asset integrity and prototype task-trace tooling.
- Added a reproducible, non-composite evaluation corpus and summarizer.
- Retained v2 iOS run manager as a read-compatible legacy tool.
