## 怎样用才不会越看越像

- 用具体任务与能力组合检索，如 `阅读 + 原位解释`、`cooking mode + ingredients`、`time scrub + continuous feedback`。行业只提供背景，不决定固定组件或页面套餐。
- 把参考变成内容对象、构图角色、状态关系或实现决定。案例中的颜色、几何、材质和参数都可重新选择；不要把几个产品的标志外观直接拼到一起。
- 原生实现、Web 实现、素材与产品观察是不同证据。代码 runtime 的许可不覆盖第三方动画资产；可在成品使用的素材也不一定能随 skill 源码分发。
- 只对实际采用的内容处理对应条件。访问受限或资料不适用时换入口，不让制作卡在登录墙；没有读取或操作的内容保持原有不确定性。

## 目录范围

本目录迁移自 2026-10-27 的研究快照，共 **117 个来源条目、55 张案例卡**。来源是独立用途的条目，不等于 117 个独立网站；同域不同文档可分别计入，重定向别名不重复计数。案例含 25 个产品、20 个交互机制、10 个建议配方。

每条保留 ID、URL、问题、平台、具体入口、访问与采用边界、实际读取范围和日期。目录不是第三方资产镜像，也没有新增爬虫、数据库、素材代理或定时同步。用普通文件检索即可；详细记录按需阅读。
