# 视觉基因

视觉基因用于描述和组合设计决策，不是风格菜单。不要先选“流行风格”，再把内容塞进去。

## 九个维度

1. **布局拓扑**：线性、分区、栈叠、对象详情、时间轴、地图、画布、编辑器、比较、仪表盘。
2. **层级与密度**：展示型稀疏、平衡任务、高密度操作、渐进披露。
3. **字体角色**：导航、阅读、数据、标题、强调、代码/等宽、CJK/Latin 混排。
4. **表面与材质**：平面、纸张、玻璃、金属、织物、液体、光、空间层级。
5. **图像策略**：摄影、实物抠图、插画、纹理、生成图、数据图形、无图像。
6. **色彩行为**：品牌、语义、层级、环境、状态与数据色分别承担什么。
7. **内容节奏**：短任务、长阅读、卡片流、时间序列、比较或编辑。
8. **平台可供性**：导航、返回、拖拽、悬停、窗口、系统手势和触感。
9. **文化与本地化**：文字密度、中英文行高、数字/单位、RTL、支付与地方语境。

## 组合方法

从任务中先确定布局拓扑、密度和核心内容角色，再选择能强化它们的字体、图像和表面。平台可供性与本地化是结构输入，不是成稿后的检查项。

同一页面建立少数稳定角色：

- 一个主角：核心对象或主要动作。
- 一条阅读路径：先看什么、如何理解、下一步在哪里。
- 2–4 个表面/文字层级：足够区分，不为每模块发明新样式。
- 一个可解释的视觉张力：尺度、裁切、对比、留白、材质或运动。

## 压力测试

任何视觉组合至少检查：长标题、空状态、错误、慢网、200% 文本、浅/深主题、目标语言和最小有效窗口。无法承受真实内容的风格不进入正式样张库。
