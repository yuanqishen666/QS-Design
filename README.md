<h1 align="center">QS Design</h1>

<p align="center">为 iPhone 和 iPad 设计漂亮、细腻、可以真实操作的页面。</p>

## 看看效果

点击上面的设计稿，或者直接[打开 Tidefold 原型](https://htmlpreview.github.io/?https://github.com/yuanqishen666/QS-Design/blob/main/ios-design/showcase/index.html)。里面有三套完整方向，每一套都可以实际操作。

## 它能做什么

- 先理解产品功能和使用场景，再确定页面的视觉主题。
- 为首页、搜索、详情、编辑等功能选择合适的布局和交互。
- 在保留原有功能的基础上重新整理信息和页面结构。
- 需要多个方向时，每个方向都会有完整功能和自己的视觉特点。
- 把转场、拖动、展开、保存和返回做成连贯的操作过程。
- 交付可以点击的原型，主要按钮、卡片和页面入口都能实际使用。
- 根据产品需要设计浅色与深色模式。

## 安装和使用

需要 Node.js 22.20 或更高版本。选择自己使用的工具，执行一条命令即可。

### Codex

```bash
npx skills add yuanqishen666/QS-Design --skill qs-ios-design -g -a codex -y
```

### Cursor

```bash
npx skills add yuanqishen666/QS-Design --skill qs-ios-design -g -a cursor -y
```

### Claude Code

```bash
npx skills add yuanqishen666/QS-Design --skill qs-ios-design -g -a claude-code -y
```

安装完成后，重新打开工具或开始一个新会话。然后直接描述想做的产品和页面：

```text
用 $qs-ios-design 给我的 iPhone 记账 App 设计一个能单手快速记录的首页。
```

也可以附上现有截图、产品说明或 SwiftUI 工程。信息够用时会直接开始设计，只有关键内容不明确时才会提问。
