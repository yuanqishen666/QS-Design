# 审美系统：建立产品自己的视觉语言

## 目标

设计应让人看出“这是这个产品”，而不是“这是某个流行模板”。原生感与品牌感并不冲突：导航、输入和系统行为保持熟悉，内容层、排版、素材和关键交互负责辨识度。

## 七个视觉决定

1. **视觉主角**：内容、数据、人物、地点、工具或动作中的一个。
2. **密度**：稀疏不等于高级；按任务速度和信息量决定。
3. **色彩角色**：背景、内容、操作、状态和品牌强调各司其职。
4. **字体角色**：正文优先语义 text styles；展示字体只用于品牌关键位置，并支持缩放。
5. **几何语言**：圆角、边缘、间距和容器嵌套要有共同逻辑。
6. **素材语言**：真内容、产品图、数据图像或定制插画优先于无意义 stock photo。
7. **材质与深度**：用来解释层级与交互，不用来证明“设计过”。

## 一个主张，少量辅助

每个方向选择一项最值得被记住的视觉或交互主张，其余元素支持它。例如：

- 路线随着旅程推进展开。
- 票券像真实牌组一样组织。
- 一张核心照片贯穿列表到详情。
- 数据结论先于图表，异常才获得高对比。

不要同时使用大面积 Glass、渐变、粒子、3D 卡片、发光边缘和弹跳字体。平均用力通常比克制更显廉价。

## iOS 原生感

- 内容层比系统 chrome 更有品牌空间。
- 使用 SF Symbols 表达通用动作；没有明确图形简称时使用文字标签。
- 深浅色不是反色处理，重新判断层级、材质、阴影和图片处理。
- 让布局适应安全区和内容尺寸，不围绕某个固定设备壳写死。
- 不把每段内容都装进卡片；先用排版、分组和留白表达关系。

## Light 与 Dark 是同一个设计

- 每个原型方向默认同时设计 Light 与 Dark；它们不是两个方向。
- 两套主题共享信息结构、视觉主角、几何语言和交互，只改变适应环境所需的颜色、材质、分隔、阴影与图片处理。
- 使用语义色彩角色，不维护两套互不相关的硬编码色板。
- Dark 不等于纯黑背景加彩色霓虹，也不等于把 Light 机械反相。
- 方向展示必须把同一页面的两套主题成对出现；实现时所有主要页面都可切换。

## 避免 AI 模板味

- 不默认暖色纸张、紫蓝渐变、全大写小标签、无意义 01/02/03、每卡一个彩色 icon。
- 不用“一个大标题 + 三张等宽卡片”解决所有首页。
- 不为了高级感降低文字对比或把正文做得过小。
- 不给与产品无关的页面添加装饰照片。
- 不把同一种圆角白卡复制到所有功能。
- 不把 Dark Mode 当成一个独立创意方向来凑数量。
